# Análise Comparativa do Escalonamento Pré-Execução de Processos em Tempo Real utilizando SMT/Z3

Implementação em Python e protocolo experimental comparativo entre o algoritmo clássico de **Xu & Parnas (1990)** e a formulação declarativa em **SMT/Z3** aplicados a uma aplicação real de monitoramento de temperatura.

*(Documentação em desenvolvimento conforme evolução das etapas.)*
